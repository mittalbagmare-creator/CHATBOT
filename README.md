Current Affairs Chatbot is a simple Python-based chatbot that provides information about important current-affairs topics such as ISRO, Chandrayaan-3, Artificial Intelligence, education, sports, the Indian budget, and climate change.

The chatbot uses a dictionary-based knowledge system to store questions/topics and their answers. It accepts questions from the user, searches for the related topic, and displays the appropriate answer. It also allows the user to type “exit” to end the conversation.

Technologies used:

Python

Dictionary

if-else conditions

for loop

String functions (lower(), strip())

User input/output
